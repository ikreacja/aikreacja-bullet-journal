# Metoda Bullet Journal - interaktywny przewodnik

Darmowy kurs do przeklikania. Uczy prowadzenia notatek odręcznych i porządkowania zadań w zeszycie metodą Bullet Journal (na podstawie książki Rydera Carrolla).

## Co robi

- 11 rozkładówek: teoria po lewej, ćwiczenie po prawej.
- Klucz symboli, schemat 4 kroków, piaskownica do testów.
- Postęp zapisywany w przeglądarce (localStorage), bez kont i bez backendu.
- Zakładka "O autorze" z linkiem do aikreacja.pl.

## Publikacja

Pojedynczy plik `index.html`, bez buildu. Vercel: preset "Other", bez komendy budowania, katalog wyjściowy = katalog główny.

## Autor

Irek Krajewski, [aikreacja.pl](https://aikreacja.pl). Nieoficjalny przewodnik, niepowiązany z marką Bullet Journal.
